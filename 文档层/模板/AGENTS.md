# 模板使用规则

本目录是待实例化模板，不作为当前项目资产索引。模板均有 YAML，但占位 URI 不是已登记对象。

新建前先查已有文件能否承担。复制到正式位置，填写标记、真实日期、唯一 URI 和关系，再运行 check。模块模板复制后文件名为 AGENTS.md；其他模板去掉“模板”后缀。

模块输入输出默认留主记录，长专题才拆出。决策只为长期取舍创建。状态变成 implemented 时把提案和计划改写为实际决定与后果，不只修改 YAML。
