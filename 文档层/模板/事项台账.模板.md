# 事项台账

一页看清：现在有哪些事、各自到哪一步、下一步谁做什么。

阶段由人或 Agent 在每次作业结束时更新；CLI 只负责定位和查询，不推断阶段。

## 阶段口径

建议固定五档，按项目实际增删：

- 候选：已记录，未决定是否做。
- 进行中：已启动，未交付。
- 待验证：产物已有，未验收。
- 已交付：验收通过，进入现行。
- 暂缓 / 已放弃：写明原因与重启条件。

阶段名称一旦启用就保持稳定；需要新阶段时在本文改写口径，不临时造词。

## 维护规则

- 一行一个事项，不把子任务拆成多行；子任务写进该事项对应的作业记录。
- 阶段变化才更新行；只改内容不改阶段时，更新「最后更新」。
- 放弃的事项保留行并写明原因，不删除，否则下一轮会重新讨论一遍。
- 关联列只放 URI，不复制决策正文；正文回决策记录读。
