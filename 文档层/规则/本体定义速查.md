# 本体定义速查

本文件是人读的类型、关系与规则层速查；机器规则源是治理层的 ontology.json，`schema` 命令返回完整定义，两处不一致时以 ontology.json 为准。

## Object Type

project 是项目入口；module 是模块主记录；document 是规则、架构、参考、步骤、验证或来源专题；decision 是长期取舍；activity 是讨论、作业和复盘；code 是源码、测试或机器接口的文件/目录资产。

模块 URI 同时标识该模块及其主记录，不另建两个需要同步的身份。输入输出保持在主记录中；机器 schema 可以登记为 code。验证记录是 document 的 verification 类别，不新建测试平台。

现行文档为 active；项目和模块用 planned/active/retired，决策用 proposed/implemented/rejected，各类型分别约束，不混成一套状态。

## Link Type

| 关系 | 表达什么 | 写入位置 |
|---|---|---|
| belongs_to | 对象属于哪个项目 | 由 project 字段生成 |
| governs | 规则约束哪个项目或模块 | 规则文档 links |
| describes | 专题说明哪个对象 | 专题文档 links |
| implements | 代码资产实现哪个模块 | assets.json，每个代码资产一个所属模块 |
| depends_on | 调用方依赖哪个模块或代码资产 | 调用方 links |
| affects | 决策或活动影响哪个对象 | 决策或活动 links |
| supersedes | 新文档完整替代旧文档 | 新文档 links，端点须同类 |
| verifies | 验证记录检查哪个对象 | 验证文档 links |
| references | 普通引用，无额外业务断言 | related 生成 |

重要关系显式登记，不从正文里的自然语言推测。一个 URI 出现在正文只能证明被提及，不能自动断言依赖或实现。链接方向决定影响查询；depends_on 从调用方指向被依赖者。

## 规则层

ontology.json 的 rule_layer 段把散文规矩登记为可校验的规则对象，由 check --logic 执行。规则约束的是类型而不是某个文件，不进入文档扫描。每条规则同时具备人能读的 statement 和机器能跑的 check，缺一不算规则。

| 字段 | 含义 |
|---|---|
| ruleId | RULE-领域-三位序号，唯一 |
| name / statement | 业务语言短名与完整陈述 |
| scope | 作用的 Object Type 与 Link Type，即规则的 governs |
| check | 规则引擎内置校验函数名与判断取值 |
| severity | error 使逻辑检查失败；warning、reminder 只报告 |
| layer | 本版均为 L3 |
| source | 规则来源的文档或决策 URI，即规则的 derived_from |
| status | active 执行；candidate 待启用；deprecated 已停用 |
| feedback | 违反时给人的方案 A、方案 B 与推荐 |

规则层的 governs（规则 → 类型）与上表的 governs（规则文档 → 项目或模块）分属不同层级，互不混用。九条规则由 doc://demo/evolution-rules、doc://demo/writing、doc://demo/module-rules 等规则文档提取，覆盖决策替代状态、影响关系、依赖与替代无环、依赖状态、项目入口登记、文档归属，以及已实施决策须被现行对象引用、待定决策不得长期悬置；`schema` 命令返回完整清单。决策三态取值、必需章节和项目归属仍由结构检查负责。

## 命名规范

- **文件命名**：现行与稳定文档用稳定描述名，不加 v1/v2/final 等版本后缀；时间序列记录（决策、作业）用 `YYYY-MM-DD-主题`；模板用 `名称.模板.md`；文件名不编码状态。
- **URI 前缀**：对象类型用小写单数前缀（project/module/doc/decision/activity/code）；模块与项目 id 用稳定小写短名，不含版本或状态。
- **类型与关系命名**：类型名用 PascalCase 稳定名；关系名用 snake_case 动词短语（如 depends_on）。命名确切对象，不用隐喻词（gate、vocabulary、surface 之类）；并列值保持对称命名。
- **位置**：URI 不嵌入机器绝对路径；本机目录只在 project.json 绑定中维护，资产位置按所属根与相对位置记录。
