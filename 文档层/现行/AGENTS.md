# 现行说明目录约束

这里只放跨模块的当前架构或专题参考；模块专属内容优先放其主记录，长内容再在该模块文档目录增加专题。现行文件写适用范围与当前行为，不写聊天时间线。

用 describes 指向项目、模块或代码资产。字段和生成清单由原始定义维护；不要在此手工复制 CLI 可生成的完整对象清单。需要保留的讨论放演进目录。
