## 跨平台指纹核对与门禁（2026-10-11）

在 Linux、Python 3.11.6、PyYAML 6.0.1 上复现本轮改动：

```powershell
python -B -m unittest discover -s "代码层/packages/governance/docgov/tests" -p "test_*.py"
python -B "代码层/packages/governance/docgov/docgov.py" --config "治理层/project.json" check
python -B "代码层/packages/governance/docgov/docgov.py" --config "治理层/project.json" check --logic
python -B "代码层/packages/governance/docgov/docgov.py" --config "治理层/project.json" check --strict --logic
```

实际结果：41 项测试全部通过（原 40 项 + 新增 1 项换行归一用例）。check 无结构错误，26 个对象、116 条关系；check --logic 执行 7 条 active 规则全部通过。

发现并修复一处跨平台问题：核对指纹对原始字节哈希，Windows 检出（CRLF）与 Linux 检出（LF）下指纹不同，导致在 Linux 上 check --strict 报“发生变化，需重新核对”，而内容并未改动。逐对象比对确认 13 个对象匹配 CRLF 变体、2 个匹配 LF、1 个（code://demo/docgov）为本次真实改动。按 decision://demo/fingerprint-normalization 在 digest() 内归一 BOM 与行尾后，重新登记核对指纹；最终 check --strict --logic 在 Linux 上通过。

另新增提交门禁：gate.py 等价于 check --strict --logic（只读），install_gate_hook.py 把门禁装成 git pre-commit 钩子（默认只在独立项目中安装，避免影响宿主仓库）。逻辑检查此前只能由收尾 Agent 手动运行，现可在提交时强制执行。

限制：本记录在 Linux 复现，与 2026-10-04 / 2026-10-11 的 Windows 记录互为跨平台佐证；指纹只证明字节级内容稳定，不判断语义一致。门禁钩子需在目标仓库安装后才生效，本包不自动修改宿主仓库。

## 工具版本统一 v4 核对（2026-10-20）

本轮对工具做了一次版本统一。此前存在三个互不包含的版本：v1 基线、v2 增加 skip_dirs、v3 增加 bundle、code_md_allow 与核对历史；v4 合并 v3 与 skip_dirs。公开版取 v4。

在 Linux、Python 3.11.6、PyYAML 6.0.1 上执行：

```
python3 -m pytest tests/ -q
python3 docgov.py --config 治理层/project.json check
python3 docgov.py --config 治理层/project.json check --logic
```

实际结果：56 项测试全部通过（原有 41 项 + 新增 15 项 test_bundle.py）；check 无结构错误；check --logic 规则层无定义错误或告警。

v4 相对本包此前版本的增量：

- `skip_dirs`：配置指定的机器状态目录（缓存、本地库）不参与指纹，也不参与「代码层含独立文档」检查。未配置时行为与旧版一致。
- `code_md_allow`：代码层 .md 的前缀白名单，用于机器消费的模板/语料说明。未配置时行为与旧版一致。
- `checkpoints.jsonl`：核对时追加历史记录（module / actor / evidence_hash / seq / at），保留「哪条意见覆盖哪一版」。原 checkpoints.json 不变。
- `bundle.py`：export / import 子命令，把项目连同 manifest 指纹、核对证据、省略声明打包为可交接单元。新增能力，不影响原有命令。

本轮修复一处真实缺陷（由新增测试发现）：`catalog.py` 构建代码资产对象时用 `pop("location")` 抹掉了 location 字段，而 `bundle.py` 打包目录型代码资产时以它为归档前缀，导致 `export --include-code` 遇目录型资产即抛 KeyError。改为保留 location 后通过。

新增 15 项测试覆盖：导出产出归档与 manifest、manifest 记录核对证据、项目主记录不可省略、未登记 URI 不可省略、活动模块验证记录不可省略、可省略项带理由、无效目录拒绝导出、导入还原文件与回执、非空目标拒绝覆盖、manifest 篡改被检出、文件篡改被检出、skip_dirs 与指纹、skip_dirs 对文档检查的边界、code_md_allow 白名单、skip_dirs 与 include_code 同时生效。

限制：v4 在本机单平台验证，其他系统与 Python 版本未逐一实测。结构与指纹只证明对象关系与字节级内容稳定，不判断语义一致。bundle 导出不执行代码、不承载凭据；导入只恢复记录与文件。
