# 示例项目

## 目标与边界

这是可复制的项目骨架。治理 CLI 已实现；业务模块 example 尚未设计和实现。复制后由 Agent 按用户的真实目标更新本记录，不把示例当作业务成果。

面向个人小项目，已有 Agent 负责生成与理解，本地工具负责确定性查询与检查。不建设团队审批、对外发布体系或模型 API 调用层。

## 当前状态

活动模块：module://demo/docgov。待填写模块：module://demo/example。后者只演示主记录结构，不提供业务代码。

架构入口为 doc://demo/architecture；工作规则为 doc://demo/agent-entry。当前已实现能力与验证证据分别见治理工具主记录及 doc://demo/tool-verification。

## 开始工作

首次使用按 doc://demo/cli-reference 初始化新项目并提供文档入口和 project.json。Agent 先读取本记录，再用 context 读取目标模块；修改前用 impact 查询依赖。完成后按 doc://demo/workflow 收尾。

小活动可只维护本记录、一个模块主记录和一份活动记录；只在内容变多或需要独立查询时增加专题。
