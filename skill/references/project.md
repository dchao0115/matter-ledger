# 项目与完整材料

- 仓库：https://github.com/dchao0115/matter-ledger
- 版本：Skill 0.1.1；完整包以仓库 main 为准
- 许可：代码 MIT，文档 CC BY 4.0

## 完整包里有什么

- 文档层：规则、模板、模块主记录、现行说明、演进记录（决策与作业）。
- 代码层：`docgov` CLI 与测试，支持 `context` / `impact` / `check` / `check --logic`。
- 治理层：项目绑定、ontology、代码资产登记、索引与核对指纹。

## 什么时候取完整包

需要跨对象查询、影响面分析、规则检查，或要把 Skill 的 starter 升级成完整治理包时。

## 版本策略

Skill 里的 `assets/starter/` 是最小工作副本，只放三份核心模板，不跟随仓库全部历史。完整材料始终以仓库为准，避免版本漂移。
